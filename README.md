# AutoCut releases

Signed AutoCut updates and installers, published automatically. AutoCut checks this feed by itself and installs
updates with one click (This Mac → Updates); there's nothing to do here by hand.

**New computer?** Download the installer from the [latest release](../../releases/tag/feed):
`AutoCut-<version>.dmg` for a Mac, `AutoCut-Windows-Beta.zip` for a Windows PC.

Every update is signed with Triumphant Media's release key and checked on each computer before it's installed.
